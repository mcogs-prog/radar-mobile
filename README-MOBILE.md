# RADAR Mobile 0.1 — test PWA

Aplikacja uruchamiana w przeglądarce. Lokalna analiza tekstu, kandydaci na twierdzenia, sygnały językowe, porównanie z 5 wklejonymi fragmentami, eksport JSON. Wyniki są heurystyczne, nie stanowią weryfikacji faktów.

Publikacja: GitHub Pages (Settings → Pages → Source: GitHub Actions). Adres: https://mcogs-prog.github.io/radar-mobile/

Dane analizowane są w pamięci przeglądarki. Kod nie wysyła tekstu do API. Strona publiczna, nie umieszczaj w repozytorium prywatnych danych.
